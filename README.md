# 광화문 점령전 V4.4 — 점령 시간 / 경제 / 무기 제작

기존 V4.3 카메라 수정판에 제작·재화·전투 보상을 통합한 3D 웹게임 **프로토타입**입니다.

## 바뀐 점

- 점령 속도: **1명당 300초에 1%** (`1/300% / second`). 5명 단독 점령 시 5배 빠르고, 서로 다른 진영이 섞여 있으면 진행이 멈춥니다. 1명 단독으로 0→100% 점령할 때 500분(8시간 20분)이 필요합니다. 서버와 로컬 모드 모두 동일 공식.
- 적군 플레이어 HP를 0으로 만들면 공격자 **25 코인** (서버 판정). 같은 팀 제압/차량 충돌/45초 내 동일 대상 반복 제압은 보상 제외.
- 로컬 체험 모드에서는 적 진영 NPC를 제압해 25 코인을 얻을 수 있습니다. 서버에 연결 중인 경우 NPC는 데모 전용이고, 서버가 플레이어 대 플레이어 전투 보상을 판정합니다.
- 나무 E → 나뭇가지 +1, 돌무더기 E → 돌멩이 +2. 온라인에선 서버가 실제 상호작용 거리와 **10초 수집 대기시간**을 확인합니다.
- B → 생존 제작대: 가지 2개로 나무 몽둥이, 가지 1개+돌 2개로 돌도끼 제작.
- 2: 맨손, 3: 몽둥이, 4: 돌도끼. 공격력 각각 20/30/38 + 성장 보너스. R 돌 투척에는 돌 1개가 소비됩니다.
- 편의점 E: 15 코인 → 간식 2개, 식당 E: 20 코인 → 포만감 +52와 체력 +15.
- 포만감 20 이상인 상태로 누적 300초 생존하면 성장 포인트 1개 지급, U → 체력/힘/최대 기력 강화. 서버가 포인트·재화를 관리합니다.
- 이동, 점령, 제작, 전투·재화 등은 서버가 주요 판정을 하고, UI의 현재 재화/성장값을 서버가 동기화합니다.

## 실행

- 로컬 체험: `index.html`을 Edge/Chrome으로 실행 (Three.js CDN 인터넷 연결 필요).
- 멀티플레이: Node.js 20+에서 `npm start` 실행 후 브라우저로 `http://localhost:3000` 접속.
- 웹 공개 배포: GitHub 저장소를 Render 같은 Node Web Service에 연결하고 시작 명령을 `node server.js`로 설정. 서버 환경변수 `ADMIN_PASSWORD`에는 12글자 이상 비밀번호를 지정하고 공개 코드에 절대 넣지 마세요.
- 일반 GitHub Pages는 단독 체험판은 가능하나 멀티플레이 서버가 필요하므로 채팅/서버 경제/점령 경쟁이 지원되지 않습니다.

## 현재 한계

- **가입·DB 영구 저장 미구현**: 재접속 시 코인, 제작 무기, 성장치는 초기화됩니다. 실제 장기 운영에는 계정 및 영구 DB 필요.
- 렌더링은 기존 Three.js 모델을 유지했으며 GPU가 없는 자동 브라우저 테스트 환경에서 실제 플레이를 검증하지 못했습니다.
- 전투 시스템은 게임 속 허구 캐릭터에 대한 비유혈 대전이며 실제 정치적 폭력과 무관합니다.
- 장기 운영 전 실사용자 부하테스트, 익스플로잇/무결성 검사, 채팅 모더레이션과 보안 개선이 추가로 필요합니다.
